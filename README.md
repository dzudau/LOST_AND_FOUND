# Lost & Found

Минималистичное веб-приложение на русском языке для публикации объявлений о потерянных и найденных вещах.

## Запуск локально
Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `lost-and-found`.
2. Загрузите в корень репозитория файл `index.html` и этот `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. Через минуту сайт будет доступен по адресу `https://ВАШ-НИК.github.io/lost-and-found/`.

## Важно
Это учебный прототип. Объявления и избранное хранятся в памяти страницы и сбрасываются после перезагрузки. Для настоящего сервиса понадобятся база данных, авторизация и серверная часть.
